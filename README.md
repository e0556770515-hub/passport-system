# ארכיון דרכונים – הוראות הפעלה

## 1. הקמת Supabase (בענן)
1. היכנסו ל-supabase.com, צרו פרויקט חדש (בחרו אזור אירופה).
2. **SQL Editor ← New query**: הדביקו את כל `supabase/schema.sql` ולחצו Run. זה יוצר טבלאות, הרשאות, אחסון פרטי ויומן פעולות.
3. **Authentication ← Sign In / Providers**: כבו את "Allow new users to sign up" (חשוב: רק מנהל מוסיף משתמשים). ב-Email ניתן לכבות "Confirm email".
4. **Authentication ← Users ← Add user ← Create new user**: צרו את המשתמש הראשון (אימייל + סיסמה, סמנו Auto Confirm). **המשתמש הראשון הופך אוטומטית למנהל.**
5. **Project Settings ← API**: העתיקו את Project URL ואת מפתח `anon public`.

## 2. הרצה מקומית
```
cp .env.example .env     # הדביקו URL ומפתח
npm install
npm run dev
```

## 3. פריסה לאינטרנט (Vercel / Netlify)
העלו את התיקייה ל-GitHub, חברו ל-Vercel או Netlify, הגדירו שני משתני סביבה `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY`. פקודת בנייה `npm run build`, תיקיית פלט `dist`.

## 4. הוספה והסרה של משתמשים
- **הוספה**: Supabase ← Authentication ← Users ← Add user. המשתמש יופיע במסך "ניהול" באפליקציה.
- **חסימה מיידית**: מסך "ניהול" ← "חסימה". המשתמש מאבד גישה לנתונים ולקבצים מיד.
- **מחיקה מלאה**: Authentication ← Users ← Delete.
- ניתן לקבוע בכל משתמש אם מותר לו להוריד קבצים, ולהפוך משתמש למנהל. מחיקת דרכונים למנהלים בלבד.

## 5. אבטחה וגיבויים
- הקבצים בדלי פרטי; צפייה והורדה רק דרך קישורים זמניים (1–2 דקות) למשתמשים מחוברים ופעילים. ההרשאות נאכפות בבסיס הנתונים (RLS), לא רק בממשק.
- Supabase מצפין אחסון ומסד נתונים במנוחה ובתעבורה.
- **גיבויים אוטומטיים יומיים קיימים בתוכנית Pro ומעלה** (לא בחינמית). מומלץ מאוד לדרכונים. גיבוי מסד הנתונים אינו כולל את קבצי האחסון עצמם, ולכן שקלו גם הורדה תקופתית של הדלי.
- הפעילו אימות דו-שלבי לחשבון ה-Supabase שלכם ולמנהלים.
